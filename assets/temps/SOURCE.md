# weather-iconic 图标

这组图标来自 Konrad Michalik 的 [weather-iconic](https://github.com/konradmichalik/weather-iconic/)，版本 [2.2.0](https://www.npmjs.com/package/weather-iconic/v/2.2.0)，依据 [CC BY-SA 3.0 US](https://creativecommons.org/licenses/by-sa/3.0/us/) 使用。完整授权文字见随附的 LICENSE。该许可证覆盖本目录内的图标及其单色、裁边与光栅化版本。

取自该版本公开发布包 [weather-iconic-2.2.0.tgz](https://registry.npmjs.org/weather-iconic/-/weather-iconic-2.2.0.tgz) 的 `package/dist/sprites.svg`。发布包的 SHA-512 已与 [temps 锁定文件](https://github.com/konradmichalik/temps/blob/89bdff520f662fe75095b59ef13d5a4e2368322c/package-lock.json) 核对一致。

SVG 保留上游图形路径和变换，将选中的 sprite symbol 分拆为单个 SVG，设置统一单色。在菜单栏使用时，按 [temps 的裁边方式](https://github.com/konradmichalik/temps/blob/89bdff520f662fe75095b59ef13d5a4e2368322c/src/lib/utils/tray-icon.ts) 以可见边界等比居中并留出 5% 边距。天气代码使用 [temps 的对应关系](https://github.com/konradmichalik/temps/blob/89bdff520f662fe75095b59ef13d5a4e2368322c/src/lib/utils/wmo-icons.ts)。
