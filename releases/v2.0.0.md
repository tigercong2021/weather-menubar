# 天气菜单栏 V2.0 · Weather Menu Bar

**2.0.0 (28) · Apple Silicon · macOS 26+**

V2.0 把天气从顶部卡片扩展到整个面板，并增加逐小时降水、穿搭提示和更完整的关注城市体验。

V2.0 brings weather across the entire panel, adds hourly precipitation and clothing hints, and redesigns the followed-city experience.

相比 1.0.1 / Since 1.0.1:

- **降水 / Precipitation:** 六个小时段的降水概率、小时趋势图与简短摘要。 / Probabilities for six hourly intervals, a trend chart and a brief summary.
- **界面 / Interface:** 原生玻璃、整页动态天空、风向驱动的雨滴与溅水、更清晰的昼夜变化。 / Native glass, animated skies, wind-driven rain and splashes, and clearer day/night transitions.
- **穿搭 / Clothing:** 菜单栏服装图标与简短悬停提示；雷雨、冻雨及较强风雨雪时补充具体说明。 / A garment icon and compact hover advice, with additional notes for thunderstorms, freezing precipitation and strong wind, rain or snow.
- **地点与空气质量 / Location and AQI:** 区县定位，以及随主城历史分布调整的平滑 AQI 色带。 / District-aware location and a smooth AQI scale adapted to the main location's history.
- **关注城市 / Followed cities:** 紧凑信息排列、选中城市的整页背景、完整独立详情；再点摘要回列表。窗口随城市数增长，屏幕不足时分页。 / Compact cards, selected-city backgrounds and dedicated details; click the summary again to return. The window grows with the list and paginates only when needed.
- **日月与亮星 / Sun, moon and bright object:** 按当前城市和时刻在本机计算位置与月相。 / Positions and lunar phase calculated locally for the current place and time.

小时降水趋势不是分钟级停雨预测；衣着与天气提醒不代表官方预警。太阳、月亮和预计最亮星点按真实位置计算，银河及其余背景星点仍是氛围素材。

Hourly precipitation trends are not minute-by-minute rain-stop forecasts, and clothing/weather hints are not official alerts. The sun, moon and expected brightest object use calculated positions; the Milky Way and other background stars remain atmospheric imagery.

This GitHub release contains source, with no DMG attached. See the [README](https://github.com/tigercong2021/weather-menubar/tree/v2.0.0#readme) for building, animations and screenshots. Test builds use ad hoc signing and are not Apple-notarized; installation, location permission and launch at login on friends' Macs still await verification.
